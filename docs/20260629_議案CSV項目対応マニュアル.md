# みらい議会＠草津市 議案CSV更新マニュアル

このマニュアルは、管理画面の「議案管理」からダウンロードできるCSVを編集し、みらい議会＠草津市の公開サイトに反映するための説明です。

CSVは「1行 = 1つの議案」です。すでに登録済みの議案を修正する場合は、ダウンロードしたCSVの該当行を編集してアップロードします。新しい議案を追加する場合は、`id` を空欄にした行を追加します。

## 基本の流れ

1. 管理画面にログインします。
2. 「議案管理」を開きます。
3. 「議案CSVをダウンロード」を押します。
4. CSVをExcelなどで開いて編集します。
5. CSV形式のまま保存します。
6. 管理画面の「編集したCSV」からファイルを選び、「CSVをアップロード」を押します。
7. 公開サイトで表示を確認します。

## 編集時の注意

- 文字化けを避けるため、ダウンロードしたCSVをそのまま編集してください。
- 既存議案を修正する場合、`id` は変更しないでください。
- 新規議案を追加する場合だけ、`id` を空欄にしてください。
- CSVに含まれていない既存議案は削除されません。
- 日付は `2026-06-08` または `2026/6/8` の形式で入力できます。
- `true` / `false` の列は、Excelで `TRUE` / `FALSE` と表示されることがありますが、アップロード時には小文字の `true` / `false` または `1` / `0` として扱えます。

## CSV項目と公開サイトでの表示

| CSV項目 | 入力例 | 公開サイトでの表示・役割 |
| --- | --- | --- |
| `id` | `xxxxxxxx-...` | 管理用IDです。画面には表示されません。既存議案の更新に使うため、消さないでください。新規追加時のみ空欄にします。 |
| `name` | `議第47号　令和8年度草津市一般会計補正予算（第3号）` | 議案の正式名称です。議案詳細ページのタイトル下に小さく表示されます。管理画面の議案名にも使われます。 |
| `status` | `introduced` | 議案の審議状況です。公開サイトの議案カードのバッジ、詳細ページの「審議のステータス」に関係します。 |
| `status_note` | `予算常任委員会で審査中` | 詳細ページの「審議のステータス」の大きな表示文に使われます。ただし `status` が `preparing` の場合は「議案提出前」と表示されます。 |
| `committee_name` | `予算常任委員会` | 詳細ページの「審議のステータス」内にある「所管委員会」に表示されます。 |
| `submitted_date` | `2026-06-08` | 議案カードと詳細ページに「2026.6.8 提出」のように表示されます。 |
| `publish_status` | `published` | 公開状態です。公開サイトに出すかどうかを決めます。 |
| `is_featured` | `true` | `true` にすると、公開中の議案の場合、トップページの「注目の議案」に表示されます。 |
| `is_review_completed` | `false` | `false` の場合、詳細ページに「この説明は確認中です。今後、内容を修正することがあります。」の案内が表示されます。`true` の場合は確認済みバッジが表示されます。 |
| `originating_type` | `mayor` | 提案者の種類です。市長提出なら `mayor`、議員提出なら `member` を入力します。主に管理・分類用です。 |
| `session_slug` | `r8-6-teireikai` | どの会期に属する議案かを指定します。会期別アーカイブページに表示するために使います。 |
| `slug` | 空欄 | 現在の運用では通常は空欄で構いません。画面には表示されません。 |
| `source_url` | `https://...` | 議案資料などの出典URLです。現在の公開画面では目立つ表示項目ではありませんが、元資料を管理するために使います。 |
| `normal_title` | `議第47号　一般会計補正予算（第3号）` | 通常表示の議案タイトルです。トップページ、アーカイブ一覧、議案詳細ページの大きなタイトルに表示されます。 |
| `normal_summary` | `物価高騰対策や公共施設整備に必要な費用を追加する補正予算です。` | 通常表示の短い説明です。議案カードと詳細ページのタイトル下に表示されます。 |
| `normal_content` | `## 何を決める議案？...` | 通常表示の本文です。議案詳細ページの本文として表示されます。Markdown形式で見出しや箇条書きを使えます。 |
| `hard_title` | `議第47号　令和8年度草津市一般会計補正予算（第3号）` | 「説明をもっと詳しく」をオンにしたときのタイトルです。空欄の場合は `normal_title` が使われます。 |
| `hard_summary` | `一般会計補正予算として、歳入歳出予算を追加補正するものです。` | 「説明をもっと詳しく」をオンにしたときの短い説明です。空欄の場合は `normal_summary` が使われます。 |
| `hard_content` | `## 補正予算の内容...` | 「説明をもっと詳しく」をオンにしたときの本文です。空欄の場合は `normal_content` が使われます。 |

## `status` の入力値

| 入力値 | 公開サイトでの意味 |
| --- | --- |
| `preparing` | 議案提出前。カードでは「議案提出前」と表示されます。 |
| `introduced` | 提出済み。カードでは「審議中」と表示されます。 |
| `in_originating_house` | 委員会審査中。カードでは「審議中」と表示されます。 |
| `in_receiving_house` | 本会議審議中。カードでは「審議中」と表示されます。 |
| `enacted` | 可決。カードでは「可決」と表示されます。 |
| `rejected` | 否決。カードでは「否決」と表示されます。 |

## `publish_status` の入力値

| 入力値 | 意味 |
| --- | --- |
| `draft` | 下書き。公開サイトには表示されません。 |
| `published` | 公開中。公開サイトに表示されます。 |
| `coming_soon` | 今後掲載予定。現在の市議会版では通常は使いません。 |

## `committee_name` の入力値

入力できる委員会名は次のいずれかです。該当しない場合は空欄にできます。

- `総務常任委員会`
- `文教厚生常任委員会`
- `産業建設常任委員会`
- `予算常任委員会`
- `決算特別委員会`
- `委員会審査なし`

## よく編集する列

通常の更新では、主に次の列を編集します。

| 目的 | 編集する列 |
| --- | --- |
| 一覧や詳細ページのタイトルを直したい | `normal_title`、必要に応じて `hard_title` |
| 議案カードの短い説明を直したい | `normal_summary`、必要に応じて `hard_summary` |
| 議案詳細ページの本文を直したい | `normal_content`、必要に応じて `hard_content` |
| 公開・非公開を切り替えたい | `publish_status` |
| トップページの注目議案に出したい | `is_featured` を `true` |
| 注目議案から外したい | `is_featured` を `false` |
| 確認中表示を消したい | `is_review_completed` を `true` |
| 所管委員会を表示したい | `committee_name` |
| 審議状況を変えたい | `status`、必要に応じて `status_note` |

## 本文で使える書き方

`normal_content` と `hard_content` はMarkdown形式で書けます。

例:

```markdown
## 何を決める議案？

この議案は、草津市の予算を追加するものです。

## ポイント

- 子育て支援に関する費用を追加します。
- 公共施設の整備費を追加します。
```

公開サイトでは、見出しや箇条書きとして表示されます。HTMLタグを直接入れる運用は避け、Markdownで書くのがおすすめです。

## CSVでは更新できないもの

次の内容は、議案CSVでは更新できません。管理画面の別メニューで編集してください。

| 内容 | 編集場所 |
| --- | --- |
| 用語解説との関連付け | 用語解説管理 |
| みらいと維新の風の見解 | 議案編集画面の「みらいと維新の風のスタンス」 |
| タグ | タグ関連の管理画面 |
| 一般質問 | 一般質問管理または一般質問CSV |

## 反映されないときの確認

- `publish_status` が `published` になっているか確認してください。
- `session_slug` が正しい会期になっているか確認してください。
- `normal_title` が空欄になっていないか確認してください。
- 日付が `YYYY-MM-DD` または `YYYY/M/D` の形になっているか確認してください。
- `is_featured` や `is_review_completed` が `true` / `false` になっているか確認してください。
- Vercelの公開サイトは反映まで少し時間がかかることがあります。必要に応じて再デプロイしてください。
